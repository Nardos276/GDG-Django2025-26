# 📝 Todo Manager Application (JSON-Based)

## 📌 Project Overview

This project is a command-line Todo Manager application developed in
Python using Object-Oriented Programming (OOP). It allows users to
create, view, update, and delete tasks. All tasks are stored in a JSON
file for permanent storage.

The project demonstrates conversion between Python objects and JSON
data.

------------------------------------------------------------------------

## 🎯 Features

-   Add new tasks
-   View tasks
-   Update tasks
-   Delete tasks
-   Save tasks to JSON file
-   Load tasks from JSON file

------------------------------------------------------------------------

## 🧱 Technologies Used

-   Python
-   JSON module
-   File handling
-   Object-Oriented Programming

------------------------------------------------------------------------

## ▶️ How to Run

Run the program using:

python main.py

------------------------------------------------------------------------

## 🔄 JSON and Object Conversion

Object → JSON: Objects are converted to dictionary using
convert_to_dict() and saved using json.dump().

JSON → Object: JSON data is read using json.load() and converted back
into objects using create_from_dict().
